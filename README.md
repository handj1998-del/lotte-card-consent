# 롯데렌터카 카드 동의서 · 원본 PDF 사본에 작성

https://handj1998-del.github.io/lotte-card-consent/

업로드한 원본 PDF는 `assets/consent/original.pdf`에 바이트 그대로 보관합니다.
SHA-256: `1a57278495f4a6ac8b8c07af37212381eda01ae80989a2d316f36e3486edd030`
원본 문구·로고·배치·빨간 표시·강조·2쪽 모두 지우거나 다시 만들지 않습니다.
로컬 pdf-lib가 원본 PDF를 열어 사본의 빈칸에 투명한 입력/날짜/서명 레이어만
추가합니다. 원본의 벡터 문구와 페이지가 그대로 보존됩니다.

- 태블릿 손가락/펜 서명, 날짜, 고객/카드 정보 입력, 미리보기, 초기화 및 새로고침.
- 카드번호 형식 및 유효기간 확인. 만료일은 원본처럼 MM/YYYY.
- 원본에 이미 있는 빨간 체크는 새 고객이 선택한 동의가 아닙니다.
  원본 보존을 위해 선택 표시를 지우거나 새 동의값으로 해석하지 않습니다.
  현재 앱은 빈칸 작성 및 서명용이며 체크 항목의 새 선택은 수집하지 않습니다.
- 모든 작성 내용/서명은 메모리에만 있으며 새로고침 시 사라집니다.
- 서버 전송, 목록/PC 동기화, 웹 저장소에 작성 데이터 저장은 없습니다.
- 이미지·원본·JS·한글 글꼴·pdf-lib는 동일 사이트에서 제공하며 외부 CDN은 없습니다.
- iPad에서는 생성된 PDF의 공유 → ‘파일에 저장’을 사용할 수 있습니다.
- 다운로드 PDF는 민감한 카드 정보가 포함될 수 있으므로 안전하게 보관하고 직접 삭제하세요.
- `Code.gs`는 이전 버전의 미사용 파일이며 현재 앱에서 호출하지 않습니다.
- 이전 서비스워커 앱 캐시는 워커 활성화 시 삭제하며 입력을 캐시하지 않습니다.

검증: JS 문법, 별도 Node Canvas/DOM 하니스에서 실제 원본 PDF 스탬핑,
Poppler로 A4 2쪽/날짜/한글/서명/원본 배경 보존 확인. 실제 태블릿과 Safari
다운로드는 수동 확인 필요. 글꼴 및 pdf-lib 라이선스는 각 asset/vendor 폴더 참조.
