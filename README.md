# 롯데렌터카 카드 동의서 · 원본 2쪽 PDF

https://handj1998-del.github.io/lotte-card-consent/

태블릿에서 원본 A4 2쪽 양식 위에 입력하고 하단 날짜와 손가락/펜 서명을
넣은 뒤 실제 PDF 파일로 저장합니다. 미리보기, 입력 초기화, 새로고침,
카드번호 형식 확인과 유효기간 확인을 지원합니다. 유효기간은 원본처럼
MM/YYYY 형식입니다. 동의 선택은 모두 미선택으로 시작합니다.

- 모든 작성 내용과 서명은 메모리에만 있습니다. 새로고침 시 사라집니다.
- PDF는 로컬 Canvas와 내장 PDF 작성기로 생성되며 서버 전송/목록/PC 동기화가 없습니다.
- 이미지·스크립트·한글 글꼴은 같은 사이트에서 제공됩니다. 외부 CDN은 사용하지 않습니다.
- PDF는 원본 배경과 입력을 합친 2쪽 A4 이미지형 PDF이며 텍스트 검색/재편집용은 아닙니다.
- iPad에서는 열린 PDF의 공유 → ‘파일에 저장’을 사용할 수 있습니다.
- 다운로드한 PDF에는 카드 정보가 있으므로 안전하게 보관하고 필요시 직접 삭제하세요.
- `Code.gs`는 이전 버전의 미사용 파일이며 현재 페이지에서는 호출하지 않습니다.
- 예전 서비스워커의 앱 캐시는 다음 워커 활성화 시 삭제하며 입력을 캐시하지 않습니다.

검증: JS 문법 검사, 별도 Node Canvas/DOM 하니스에서 두 페이지 PDF 생성,
Poppler로 A4 2쪽/날짜/한글/서명과 배치 확인. 실제 태블릿과 Safari 다운로드는
수동 확인이 필요합니다. 한글 글꼴 라이선스는 assets/consent/OFL.txt 참조.
